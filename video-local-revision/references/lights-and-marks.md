# 灯光、标识与局部外观

## 先确定对象与时序

辨认灯具本体、发光核心、光晕和周围受光。灯珠变亮、辉光增强、车漆反光变亮是不同变化，不能用一个全局亮度值代替。区分印刷图案、车标、几何边线与随视角移动的反光。

涉及声音或动作时，定位原片的实际触发帧：例如鞠躬与提示音。把要求表达为“初始状态 → 触发变化 → 过渡 → 保持状态”，明确顶部灯、竖灯和辉光分别如何变化。用户若要求保留原辉光后慢慢降到常亮，就保留这一过渡，结尾不能回到熄灭状态。此规则只适用于有该要求的任务。

## 可选做法

稳定的局部平面可使用跟踪后的遮罩、透视贴合或重投影；明显曲面、视角变化或遮挡需要更贴合表面的表示。灯体最好由原片可信区域或参考结构确定。亮度与辉光可以分开控制，但不要求特定图层或软件。

替换文字或车标时同时考虑透视、曲率、字形、尺寸、清晰度和原场景照明。清除旧标识的残影，再与底材结合。不要把整张带工作室反光的参考照片直接当作车身纹理。

## 定位常见问题

| 现象 | 优先检查 |
| --- | --- |
| 结尾灯珠“飘” | 跟踪锚点是否属于灯壳；透视、尺度与局部形变是否跟随；不要仅靠加大模糊掩盖错位 |
| 顶部灯关闭后有亮边 | 是否还残留旧发光像素、光晕或补底边界；同时辨认真实车漆高光 |
| 灯亮度突然跳变或结束时灭掉 | 过渡曲线、片段拼接和最后一帧的保持值 |
| 标识周围出现固定亮斑 | 是否把参考照片里的照明烘进了贴图 |
| 声音与闪光错开 | 原片时间戳、裁剪起点、帧率和事件帧，而非只看播放器四舍五入后的秒数 |

检查触发前、峰值、衰减、保持和最后一帧，再原速看过渡。灯壳贴合与发光观感分别判断；高亮时看不出的错位可能在变暗后暴露。
