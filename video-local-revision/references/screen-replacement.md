# 平面屏幕内容替换

## 先确定要改哪一层

- **只改文字、数字或图标**：把参考图当作指定元素的内容基准。以原片为当前帧的底片，只清除旧元素并合入新元素，保留其余界面、玻璃、边框和前景。返修时沿用已确认的区间外画面。若口头描述和画框指的是不同内容，先确认具体区域。
- **整屏换画**：区分有效显示区域与实体边框。确认替换内容是静态图还是视频。比例不同时，“铺满、比例不变、内容完整”无法兼得，先确认裁切、等比留边或拉伸。屏幕在画面中的投影和视频画布比例都不能代替屏幕自身比例。

## 跟踪：用原片上的证据

在一帧清晰画面上定好有效显示边界或原字基线，从原片选取随显示面一起运动的稳定特征，例如屏幕内边线或固定的图表折点。摄像头开孔与外框适合辅助定位，先检查它们与显示面是否有可见视差。手指用于确定遮挡，扫过的高光用于匹配反射。以清晰帧建立绝对位置。若特征随斜视、强反光或失焦丢失，用其余可见特征与前后清晰帧约束位置，并标记需要复核的估计帧。

近似平面的屏幕可先用平面透视映射。能看到四角并稳定贴合时，无需追加跟踪算法。若外框看起来稳、内部字仍跳，先把几帧拉正到同一屏幕坐标，检查原字位置，再用目标附近的同平面特征做局部校准；必要时双向核对相邻帧，配合清晰帧纠偏，避免只做逐帧累积或一味平滑。若一直在同方向错位，则先查锚点、排版基线或坐标变换。镜头畸变、弯曲屏幕、折射或明显非平面形变可换用其他映射方法。

## 整屏换画

1. **准备画面。** 根据已确认的比例处理裁切、留边或拉伸。替换素材是视频时，确定素材从哪一帧开始、在原镜头持续多久，以及何时切回。素材不足以覆盖指定时长时，确认是否允许循环、定格或其他处理。
2. **贴合显示面。** 把准备好的画面映射到逐帧跟踪的有效显示区域。保留实体边框，分别处理玻璃反射和手指等前景遮挡。用斜视、边缘出画或遮挡变化明显的片段核对角点和四边。
3. **复核播放。** 对照同一时点检查插入视频的首末帧、边缘和反光。看原速播放与两端接点，确认素材时间、显示面跟踪和前景遮挡连续。

## 局部换字与图标

先和参考逐项核对要替换的文字或数值，包括负号、小数点、百分号和单位。用参考确定图文内容，用原片确定基线、位置及保留区域。

1. **清旧内容。** 只遮住旧笔画及边缘残影。优先用干净底片；没有时，可从同一帧旧字上方、行间和下方取样恢复玻璃底色和光影，前提是这些区域没有别的图文且反光连续。复杂反射或背景纹理需要另选补底方法。不要把补底遮罩扩到未授权的折线或刻度。
2. **贴新内容。** 在拉正的屏幕坐标铺排，匹配原字位置、行距、大小、清晰度和原片运动模糊。随逐帧跟踪映射回去，让扫过的反光也改变新字在各处的对比度；不要把亮斑固化在字上。整屏换画同样保留需要的玻璃反射和最前面的手指等遮挡。
3. **接回原片或已确认段。** 先对齐位置和清晰度，再处理亮度过渡。两层字没对齐时直接交叉淡化会出现双影；需要过渡时可保持一套字形，过渡其颜色或亮度。范围较小时先预览最容易露馅的几帧及接点，再导出所需交付。

## 判断失败位置

| 现象 | 优先检查 |
| --- | --- |
| 右上角或上沿偏斜 | 角点是否取在实体边框、透视模型是否适用、跟踪是否漂移 |
| 边缘露出旧界面 | 显示区域定义和每帧边界，不要直接把贴图扩大到边框外 |
| 四角吻合但中间边线偏离 | 镜头畸变、屏幕曲率或映射模型 |
| 插入画面突然变形 | 特征失配、低质量角点、插值或帧索引错位 |
| 前景被覆盖 | 缺少遮挡遮罩或遮挡时序错误 |
| 字在反光扫过或手机翻转时横跳 | 反光被误当跟踪点、斜视时特征失配；先对照原片中同一帧可见的固定结构 |
| 新字发灰、浮在反光上或像双层字 | 分别检查补底残影、反光下的字面反差、运动模糊和接点是否叠了两套字 |
| 未修改的刻度变淡或偏色 | 先检查遮罩和局部合成范围，再核对导出的色彩矩阵、范围和转码 |

## 查实际输出

并排看原片和成片的同一帧，检查目标、未改内容、最强反光和修改区间的前后帧，再看原速播放。整屏换画看四角和边界。只改元素时看新旧位置基线、折线及刻度的颜色是否连续，并核对实际输出的字符。按帧指定区间时，先核对原片帧率、时间码基准及末帧是否计入。预览和母版都按同一时点对照。需要定位具体帧时，可用[局部对照](tools.md#局部对照)。

如果肉眼难区分是原片运动还是合成抖动，可从解码后的源片和成片独立测位置：逐帧比较目标相对未改锚点的偏差，再查偏差在相邻帧之间的变化。前者找持续错位，后者找跳动；报告代表值和最差的可信区段，并单列低置信度帧。按目标在当前镜头中的大小与可见程度判断误差。
